A Minecraft mod that lets you access your storage from anywhere, without walking back and forth to your chests.

> **Status:** This mod is under active development. Support for **Fabric** and **Forge** is planned for the main versions in the future.

## Features

- **Connect chests and other inventories:** Link chests, barrels, and inventories from other mods to a single terminal, then open that terminal to see and manage everything in one place.
- **Upgrades:** Expand what your terminal can reach. Upgrades increase the distance and dimensions your connected inventories can be accessed from.
- **Multiplayer security:** The first player to connect an inventory becomes its owner. Other players can look at the storage, but only the owner can change it.

## Easy to Learn

The mod is designed to be self-explanatory. In-game descriptions show you how each block, item, and screen works, so you can learn as you play.

## Configuration

The mod includes a server configuration file. It lets server administrators decide whether an inventory that is already linked to one terminal can be connected to another.

## Compatibility

The mod includes compatibility with the following mods:

- **Sophisticated Storage:** Manage connected Sophisticated Storage inventories from the terminal.
- **Sophisticated Backpacks:** Manage connected backpacks from the terminal.
- **Storage Drawers:** Manage connected drawers from the terminal.
- **EMI:** Browse stored items from the recipe viewer.
- **JEI:** Browse stored items from the recipe viewer.
- **REI:** Browse stored items from the recipe viewer.
